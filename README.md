# 🍬 설탕 도망쳐! — 애벌레 술래잡기

주방과 마당을 무대로 한 3인칭 3D 술래잡기 게임입니다. 브라우저에서 바로 실행됩니다.

## 실행 방법

`index.html`을 브라우저로 열면 끝입니다. (three.js는 `vendor/`에 포함되어 있어 인터넷 없이도 동작합니다.)

로컬 서버로 열고 싶다면:

```
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 조작

| 키 | 동작 |
| --- | --- |
| ↑ ↓ | 앞으로 / 뒤로 이동 |
| ← → | 방향 회전 |
| Space | 점프 |
| 마우스 드래그 | 시점 회전 |
| R | 재시작 |

## 규칙

- **레벨**: 살아남은 지 1분이 지날 때마다 레벨이 올라가고, 다음 캐릭터로 변신합니다.
  몸집이 커질수록 숨을 곳이 줄고 애벌레는 빨라집니다.
- **술래**: 애벌레 한 마리. 가구 위든 마당이든 어디든 타고 넘어 다니며, 닿으면 그 과일·채소는 죽습니다.
  애벌레 크기는 블루베리 5개를 이은 정도입니다.
- **AI 친구**: 나머지 7종이 함께 돌아다니다가 애벌레를 보면 도망칩니다. 잡히면 아웃됩니다.

## 캐릭터와 은신처

| 순서 | 캐릭터 | 숨을 수 있는 곳 |
| --- | --- | --- |
| 1 | 설탕 (작은 사각형) | 작은 구멍 전부 + 잔디밭 |
| 2 | 블루베리 | 작은 구멍 + 파란 머그컵·파란 러그 |
| 3 | 키위 | 몸집에 맞는 구멍 |
| 4 | 토마토 | 몸집에 맞는 구멍 |
| 5 | 양배추 | 배수관 구멍 정도만 |
| 6 | 수박 | 없음 |
| 7 | 멜론 | 없음 |
| 8 | 코코넛 | 없음 |

## 환경

10×10 크기의 주방에 주전자, 프라이팬, 열린 서랍, 파란 머그컵, 오븐, 냉장고, 식탁, 의자가 있고,
문 밖 마당에는 잔디밭, 책상, 화분이 있습니다. 모든 사물에 충돌 판정이 있습니다.

## 트램펄린

노란 발판 4개가 **서랍 앞 / 식탁 옆 / 마당 책상 앞 / 냉장고 앞**에 있습니다.
밟으면 약 0.5초 만에 포물선을 그리며 해당 가구 위로 자연스럽게 올라갑니다.
